# Cardiomics-Sequence-to-Function

[![Documentation Status](https://readthedocs.org/projects/cardiomics-sequence-to-function/badge/?version=latest)](https://cardiomics-sequence-to-function.readthedocs.io/en/latest/?badge=latest)

Collection of Tools and pipelines to train and finetune sequence to dunction models on pseudobulked scMultiome and bulk CutnTag data.

## Documentation

Detailed documentation for this project is available on [Read the Docs](https://cardiomics-sequence-to-function.readthedocs.io/).

The documentation includes:
* **Getting Started:** Installation and environment setup for AlphaGenome and Borzoi.
* **Pipeline Guides:** Step-by-step instructions for running data preprocessing and model fine-tuning.
* **API Reference:** Comprehensive docstrings for the Python utility modules.
* **Scripts:** Command-line arguments for all `.sh` and `.slurm` cluster submission scripts.
