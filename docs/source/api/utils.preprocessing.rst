CLI Usage Examples
------------------

**make_AG_input_config.py**

Usage:

.. code-block:: bash

    python src/utils/preprocessing/make_AG_input_config.py \
        --data_dir [DATA_DIR] \
        --modality_folders [MODALITY_FOLDERS ...] \
        [OTHER_ARGS]

Input arguments:

.. code-block:: text

    -h, --help: Show help message with arguments and their descriptions, and exit
    --data_dir (required): Base path to bigwig input data directories
    --modality_folders (required): List of subfolders in data_dir corresponding to modalities. Must contain ATAC, RNA, or CutnTag in name.
    --config_prefix: Path and name of the output YAML file
    --nonzero_means: CSV file generated by 00_compute_nonzero_means_per_bw.sh
    --norm_tag: Tag to filter and clean normalized bigwig files (default: None)
